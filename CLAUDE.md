# E.ON Atlassian ops repo

Jira DC [track.eon.cz](https://track.eon.cz), Confluence DC
[dory.eon.cz](https://dory.eon.cz), projekt **AIC**. Vše přes MCP `atlassian-eon`.

**Načti skill `eon-atlassian`** — drží změřená fakta a pasti Data Center.
Neimprovizuj z paměti, API DC se liší od Cloudu.

Platí i bez načteného skillu: **tokeny žijí jen v `.env`** (gitignored, nikdy je
nevypisuj) a **zápis do Jiry/Confluence potvrď v chatu předem**, po zápisu přečti
objekt zpět.
